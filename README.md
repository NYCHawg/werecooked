# We're Cooked

Family meal planning: weekly plan (cooking in, eating out, takeout, leftovers, nobody home), shared pantry with par levels, family recipe book, and a shopping list built from the week's meals and low stock. Data syncs live between everyone in the household through Supabase.

- **iPhone / any browser:** https://nychawg.github.io/werecooked/ (Safari › Share › Add to Home Screen)
- **Android:** download `WereCooked.apk` from the latest release.

`web/` is the app. `android/` wraps it in a WebView. Every push to `main` redeploys the web app and builds a new APK release.
